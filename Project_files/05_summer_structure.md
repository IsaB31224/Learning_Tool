# Summer Structure
*Part of the Knowledge Transfer Project planning series — June 2026*

---

## Schedule

**Mornings — DSA / project build**
DSA learning is integrated into the project build. When a structural problem is encountered during the build, the appropriate data structure is learned and implemented at that moment. The NeetCode roadmap is used as a progression reference — it informs what to reach for next, not a separate syllabus to work through. Prerequisites for any structure not naturally appearing in the project are handled standalone as needed. Only data structures with a genuine home in the project will be built.

**Afternoons/Evenings — Project build**
