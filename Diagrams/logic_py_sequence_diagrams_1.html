logic.py — sequence diagrams

Both calls that tool2_reflection/logic.py makes, from the UI click through to the response landing back in ui.py

Flow 1 — Generate Questions

Triggered by the "Generate Questions" button after metadata and initial reflection are submitted.

Note — the UI never calls the API directly. It always hands off to a QThread worker, so the interface stays responsive while Claude is generating a response.

Flow 2 — Generate Final Question

Triggered after all three question responses are filled in.

Note — this call needs the full accumulated context — source content, initial reflection, and all three question/response pairs — not just the latest input. It's a synthesis step, not another isolated question.
